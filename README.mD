En este repositorio se almacenarán ejercicios, prácticas y proyectos desarrollados durante el curso.

### Python

Python es un lenguaje de programación de alto nivel, sencillo y versátil. Se utiliza para desarrollar aplicaciones, automatizar tareas, trabajar con datos y crear aplicaciones web.

En este repositorio se utilizará Python como lenguaje principal para los ejercicios y proyectos.

### Odoo

Odoo es una plataforma de gestión empresarial de código abierto. Permite administrar diferentes procesos de una empresa mediante módulos, como ventas, inventario, compras y contabilidad.

En este repositorio se realizarán prácticas relacionadas con el desarrollo y personalización de módulos de Odoo.

### Django

Django es un framework web desarrollado en Python que permite crear aplicaciones web de forma rápida, segura y organizada.

Proporciona herramientas para trabajar con bases de datos, usuarios, URLs, plantillas y la lógica de las aplicaciones web.

## Contenido del repositorio

- Ejercicios de Python
- Prácticas con Odoo
- Proyectos con Django
- Ejercicios de programación
- Documentación de los proyectos

## Objetivo

El objetivo de este repositorio es almacenar y organizar los trabajos realizados durante la materia de Programación 2, aplicando conocimientos de programación y desarrollo de aplicaciones.
